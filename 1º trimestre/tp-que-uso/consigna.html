Objetivo general

Que el alumnado sea capaz de seleccionar y justificar el método de array y el evento adecuados para resolver un problema concreto de una interfaz web, y de implementarlos correctamente en JavaScript.

Objetivos específicos

  • Distinguir qué devuelve cada método de array (forEach, map, filter, find, some, includes, reduce, sort) y elegirlo según el resultado buscado.
  • Identificar el evento apropiado para cada interacción (ratón, teclado, foco, entrada de texto) y el elemento donde conviene escucharlo.
  • Aplicar la propagación de eventos: diferenciar event.target de event.currentTarget, usar la delegación y stopPropagation().
  • Modificar el DOM a partir de un estado: renderizar listas, cambiar clases y estilos.
  • Justificar por escrito cada decisión técnica antes de programarla.

Resultados de aprendizaje relacionados

  • Programa código para clientes web utilizando estructuras definidas por el usuario (arrays y objetos).
  • Desarrolla aplicaciones web interactivas integrando mecanismos de manejo de eventos.
  • Desarrolla aplicaciones web aplicando las características del modelo de objetos del documento (DOM).

Herramientas que vas a necesitar

  • event.target: el elemento exacto donde ocurrió el evento.
  • event.currentTarget: el elemento que tiene el listener.
  • elemento.closest(".clase"): sube desde el elemento (incluido) hasta encontrar uno que coincida. Si no hay, devuelve null.
  • event.stopPropagation(): el evento deja de subir a los padres (corta el burbujeo).
  • elemento.classList.add / remove / toggle / contains("clase"): poner, sacar, alternar o preguntar por una clase.
  • elemento.textContent: el texto de un elemento. input.value: lo que se escribió en un input.
  • texto.toLowerCase().includes(otro): buscar sin importar mayúsculas.
  • [...array]: hace una copia del array (útil antes de sort).

🐞 Si algo no funciona

  1. Mirá la consola (F12): ¿hay un error en rojo? Leelo, dice la línea.
  2. ¿El querySelector encontró el elemento? Hacé console.log(elemento): si sale null, el selector está mal.
  3. ¿El evento se dispara? Poné un console.log("entró") como primera línea del listener.
  4. ¿Qué es realmente event.target? Hacé console.log(event.target) y mirá qué elemento sale.

Ejemplo con eventos

Escenario: en el chat del juego, cuando el usuario aprieta Enter en el input, el mensaje se agrega a la lista y el input se vacía.

// Decisión: keydown en el input del chat, porque necesito saber QUÉ tecla
// se apretó (event.key). Con "input" no sé si fue Enter, y "change"
// solo se dispara al salir del campo.
const chat = document.querySelector(".chat-entrada");
const mensajes = document.querySelector(".chat-mensajes");

chat.addEventListener("keydown", (event) => {
    if (event.key !== "Enter") return;
    if (chat.value.trim() === "") return;

    const item = document.createElement("li");
    item.textContent = chat.value;
    mensajes.appendChild(item);
    chat.value = "";
});
