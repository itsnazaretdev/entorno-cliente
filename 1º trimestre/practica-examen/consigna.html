Objetivo general

Que el alumnado sea capaz de construir una interfaz interactiva siguiendo el patrón estado → renderizar() → eventos: pintar una lista a partir de un estado, filtrarla con un único listener delegado y mostrar totales calculados.

Objetivos específicos

  • Guardar en una variable de estado lo que el usuario elige (categoría, elemento seleccionado).
  • Escribir una función renderizar() que vacía y vuelve a pintar la lista a partir del estado.
  • Obtener los elementos visibles con filter sin modificar el array original.
  • Usar un solo listener delegado en el contenedor, con closest y textContent, que solo cambia el estado y llama a renderizar().
  • Calcular cantidades y totales de los elementos visibles con length y reduce.
  • Programar componentes de cabecera: un menú que se cierra con un clic afuera y un panel que se cierra con Escape.
  • Encontrar y corregir los errores clásicos del patrón.

Los tres errores clásicos

Filtrar el original

lista = lista.filter(...) pierde elementos para siempre. Guardá el resultado en otra variable.

Listener dentro de renderizar()

Cada pintada suma otro listener y los clics se multiplican. El listener va afuera, una sola vez.

Olvidar renderizar()

Al cargar la página y al final de cada evento. Si no, el estado cambia pero la pantalla no.

🧩 Ejemplo resuelto (con datos que no están en la práctica)

Escenario: una biblioteca muestra sus libros. Hay botones "Todos", "Novela" y "Ciencia" en .temas; la lista se pinta en .libros y debajo se muestra el total de páginas de los libros que se ven.

const libros = [
    { titulo: "El faro", tema: "Novela", paginas: 320 },
    { titulo: "Átomos para todos", tema: "Ciencia", paginas: 180 },
    { titulo: "La última carta", tema: "Novela", paginas: 250 }
];

// 1) ESTADO: lo que eligió el usuario
let temaActivo = "Todos";

const contTemas = document.querySelector(".temas");
const listaLibros = document.querySelector(".libros");
const totalPaginas = document.querySelector(".total-paginas");

// 2) RENDERIZAR: pinta todo a partir del estado
function renderizar() {
    // Decisión: filter, porque quiero VARIOS libros (los del tema) sin modificar libros.
    let visibles = libros;
    if (temaActivo !== "Todos") {
        visibles = libros.filter(libro => libro.tema === temaActivo);
    }

    // Decisión: forEach, porque por cada libro creo y agrego un li.
    listaLibros.innerHTML = "";
    visibles.forEach(libro => {
        const item = document.createElement("li");
        item.textContent = `${libro.titulo} (${libro.paginas} páginas)`;
        listaLibros.appendChild(item);
    });

    // Decisión: reduce sobre los visibles, porque junto sus páginas en UN número.
    const suma = visibles.reduce((acumulador, libro) => acumulador + libro.paginas, 0);
    totalPaginas.textContent = suma;
}

// 3) EVENTO: un solo listener, afuera de renderizar()
// Decisión: click en .temas (delegación) + closest("button"), porque todos los botones hacen lo mismo.
contTemas.addEventListener("click", (event) => {
    const boton = event.target.closest("button");
    if (boton === null) return;   // clic en el hueco entre botones

    temaActivo = boton.textContent;  // solo cambia el estado...
    renderizar();                    // ...y vuelve a pintar
});

renderizar();  // pintar la primera vez, al cargar

Fijate en el orden

El evento no pinta: cambia temaActivo y llama a renderizar(). Y renderizar() no pone listeners. Si mantenés esa separación, el integrador sale solo.
